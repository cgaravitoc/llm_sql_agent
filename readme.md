# Chatbot Project

This project is a chatbot application designed to provide automated responses to user queries. It can be customized to handle various use cases such as customer support, FAQs, or general conversational AI.

## Features

- Natural language processing for understanding user input.
- Customizable responses and behavior.
- Built with **Streamlit** for a user-friendly interface.
- Utilizes **LangChain** for advanced conversational AI capabilities.
- Supports deployment with **Docker** for easy containerization.

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd chatbot
   ```
## Usage

1. Start the development server:
    ```bash
    sh start
    ```

2. Before using the chatbot, ensure you have configured the following environment variables:
    - **API Key**: Your API key for accessing the language model.
    - **URL Endpoint**: The endpoint URL for the API.
    - **Model Name**: The name of the model to be used for generating responses.

3. Open your browser and navigate to `http://localhost:8502` to interact with the chatbot.
